# Эксперимент статьи: LLM и агенты на 85 эталонах

Запуски 10–11 ноября 2026 г. Модели вызывались через сторонний шлюз, совместимый с OpenAI API, поэтому проверить, какие именно версии моделей отвечали, нельзя.

| Модель | Идентификатор в шлюзе |
| --- | --- |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` |
| GPT-6.1 Sol | `gpt-6.1-sol` |
| DeepSeek-V4-Pro | `deepseek-v4-pro-0813` |

Как запускали:

```sh
python agent/run_experiment.py --budget 22000000 --results results
python agent/analyze.py experiment/results
```

## Файлы

| Файл | Что в нем |
| --- | --- |
| `results/runs_<модель>.jsonl` | Каждый запуск: вопрос, ответ, оценки, токены, время и вся переписка с вызовами инструментов |
| `results/failed_defects_<модель>.jsonl` | Первые проверки дефектов с пустым отчетом: модели не хватило 12 запросов. Эти 7 проверок повторены с лимитом 20 запросов |
| `results/analysis.json` | Таблицы статьи: точность, причины ошибок агентов, счетчики выбросов IQR при разных формулах |
| `results/defect_annotation.csv` | Независимая разметка 15 отчётов о дефектах двумя разметчиками по контрольному списку; отчёты были обезличены (R01–R15) |
| `results/false_defects.csv` | Есть ли в отчёте ложные утверждения о дефектах, по оценке каждого разметчика |

## Итоги

Число верных ответов из 85 при оценке по правилам статьи:

| Модель | Без инструментов | Агент, формулировка пакета | Агент, протокол статьи |
| --- | --- | --- | --- |
| Claude Sonnet 5.5 | 10 | 77 | 79 |
| GPT-6.1 Sol | 5 | 85 | 84 |
| DeepSeek-V4-Pro | 10 | 71 | 80 |

Все 34 ошибки агентов либо остались без итогового ответа, либо связаны с вопросом о выбросах IQR и неоднозначной формулировкой правила пакета. Подробности приведены в статье.
