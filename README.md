## 🛠 Описание решения

В данном репозитории реализован легковесный ИИ-агент на базе **Claude** (через OpenRouter API) и **Pandas**, предназначенный для автоматизированного анализа CSV-таблиц. 

Агент оснащен инструментами (Tools) для:
1. **Чтения структуры данных (`read_csv`)** — получения размеров таблицы, списка колонок, типов данных, первых строк и базовой статистики.
2. **Выполнения запросов (`query_csv`)** — динамического выполнения операций Pandas по текстовому запросу пользователя.

## Датасеты

Для исследования подготовлены пять CSV за **май–сентябрь 2026 года** из открытой серии **Empresa Municipal de Transportes de Madrid (EMT)** о количестве свободных мест и вместимости парковок Мадрида. Каждая запись содержит дату, час и идентификатор парковки, а также число свободных мест и общую вместимость.

Источники: [портал открытых данных EMT](https://datos.emtmadrid.es/dataset/aparcamientos-por-mes-y-anio) и [каталог открытых данных Мадрида](https://datos.madrid.es/dataset/900032-0-emt-aparcamientos-plazas). Исходные файлы сверены с официальными загрузками **14.10.2026**; их контрольные суммы сохранены в `manifest.json` внутри архива.

Во всех файлах одинаковые шесть полей и 82 идентификатора парковок. Исходная сетка содержит запись для каждой комбинации «дата — час — парковка». Разница в числе строк обусловлена продолжительностью месяца: 30 или 31 день. Это месячные срезы одной серии; число допустимых измерений и распределение свободных мест между месяцами различаются.

### Структура данных

| Поле | Содержание |
| --- | --- |
| `dateServ` | Дата в формате `YYYY-MM-DD` |
| `hour` | Час от 0 до 23; часовой пояс в метаданных не указан |
| `idParking` | Идентификатор парковки |
| `isEmtPark` | Служебный флаг `True` / `False`; точное определение в доступном словаре не раскрыто |
| `freeParking` | Количество свободных парковочных мест |
| `parkingSpaces` | Общая вместимость парковки |

Исходные CSV читаются как UTF-8, разделитель — запятая. Пустые ячейки и дубликаты не обнаружены, но в `freeParking` есть отрицательные значения, включая `-1`, и значения выше вместимости. Для количественных эталонов применён единый фильтр **P1**, описанный в отчёте и скрипте: после проверок структуры и типов сохраняются записи с положительной вместимостью и `0 ≤ freeParking ≤ parkingSpaces`. Нули сохраняются; недопустимые значения исключаются без замены и интерполяции.

После проверки осталось **105 825 записей по 30 из 82 парковок**. Средние и доли занятости относятся к этим допустимым наблюдениям. По ним нельзя оценивать занятость всего парковочного фонда города. Пять месячных файлов также нельзя считать пятью независимыми источниками данных.

### Зачем эти данные нужны в исследовании

Датасеты служат общим входом для сравнения языковых моделей и ИИ-агентов. На них можно проверять чтение структуры CSV, выявление недопустимых значений, фильтрацию, расчёт среднего и медианы, группировку по парковке и часу, поиск максимумов и обработку совпадающих результатов. Одинаковая схема позволяет задавать одни и те же задания для разных месяцев.

Для проверки ответов подготовлены воспроизводимые расчёты на Python и **85 вопросов с эталонными ответами, единицами измерения и допусками**. Они позволяют оценивать правильность анализа по заранее заданным правилам. Сам эксперимент по сравнению моделей и агента проводится отдельно; подготовка данных не содержит его результатов.

### Готовые материалы

[**Скачать архив с датасетами и эталонами**](parking_team_package_no_pdf.zip?raw=true)

После распаковки все материалы находятся в папке `parking_team_package/`:

| Файл или папка | Назначение |
| --- | --- |
| `data/` | Пять исходных CSV без изменений |
| `report.md` | Описание источника, аудит качества, правила обработки и основные показатели |
| `tables/benchmark.csv` | Основные эталонные показатели по месяцам |
| `tables/reference_answers.csv` | 85 вопросов с проверенными ответами и допусками |
| `TABLES.md` | Описание столбцов таблиц результатов и единиц измерения |
| `check_parking.py` | Скрипт повторного расчёта |
| `manifest.json`, `source_verification.json` | Версия исходников, ссылки, контрольные суммы и проверка источника |
| `validation.json`, `CHECKSUMS.sha256` | Результаты проверки расчётов и контрольные суммы файлов пакета |

Для повторного расчёта нужен Python 3.10+ без дополнительных библиотек. Из папки `parking_team_package/`:

```sh
python3 check_parking.py --input-dir data --output-dir reproduced
```

Скрипт не меняет исходные CSV и сохраняет результаты в отдельную папку. Эталонные ответы относятся к версии файлов из архива: если официальные ресурсы позднее обновятся, результаты могут измениться.
