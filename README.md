## 🛠 Описание решения

В данном репозитории реализован легковесный ИИ-агент на базе **Claude** (через OpenRouter API) и **Pandas**, предназначенный для автоматизированного анализа CSV-таблиц. 

Агент оснащен инструментами (Tools) для:
1. **Чтения структуры данных (`read_csv`)** — получения размеров таблицы, списка колонок, типов данных, первых строк и базовой статистики.
2. **Выполнения запросов (`query_csv`)** — динамического выполнения операций Pandas по текстовому запросу пользователя.
