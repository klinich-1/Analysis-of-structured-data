# Аудит пакета эталонов

Здесь лежит скрипт, который заново считает показатели статьи об устойчивости эталонных ответов из пяти исходных CSV. В пакете `parking_team_package` исходные данные и эталоны не менялись.

## Запуск

Нужен Python 3.10+, дополнительные библиотеки не требуются. Распакуйте `data/parking_team_package_no_pdf.zip` в корень репозитория и выполните из корня:

```sh
python audit/audit_repro.py --data parking_team_package/data --refs parking_team_package/tables/reference_answers.csv --out audit/audit_results.json
```

Скрипт не обращается к сети и не меняет входные файлы.

## Что считается

- дефекты данных: значение −1, превышения вместимости, парковки без допустимых значений;
- застывшие отрезки при пороге 24 и 12 часов и вариант очистки P1-S;
- занятость по строкам и с весом вместимости для P1 и P1-S, пиковые часы, самая загруженная парковка;
- чувствительность эталонов к округлению, поправке ddof, методу квартилей и фильтрации;
- структура общесистемных сбоев и завышенная вместимость ID 32;
- контроль покрытия при сравнении месяцев и критерий знаков для августа.

## Результаты

`audit_results.json` содержит результат последнего запуска.
